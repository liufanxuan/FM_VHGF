# Third-party code and weights

This project includes adaptations of OpenCLIP and timm and an adaptive hyperedge implementation based on HyperACE/YOLOv13. The relevant upstream license texts are in `LICENSES/`.

- [OpenCLIP](https://github.com/mlfoundations/open_clip)
- [timm](https://github.com/huggingface/pytorch-image-models)
- [BiomedCLIP weights](https://huggingface.co/microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224)

A separate license for this project's original contributions has not been assigned.
