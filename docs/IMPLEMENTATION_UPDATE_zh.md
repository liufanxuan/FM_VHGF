# FM-VHGF 代码修改说明

本次以当前 `Manuscript_ESWA_final.docx` 的方法和训练协议为依据，在恢复工程的基础上整理了一个正式入口明确的 PyTorch 实现。修改版用于后续训练与代码公开；原论文的临床结果尚未通过这一修改版重新验证。

## 已完成的修改

| 部分 | 当前实现 |
| --- | --- |
| 编码器 | PET/CT 分别使用 3D patch 投影、CLS/register token 和 LayerNorm；共享位置嵌入及冻结的 Transformer 注意力/MLP。 |
| 层级表征 | 每个 block 输出经分支归一化，结合 CLS 和 register token，形成各模态的逐层节点。 |
| 超图 | 分别构建 PET/CT 自适应超图，完成模态内聚合，并使用另一模态的参与矩阵进行双向更新。 |
| 分类与损失 | 更新后节点拼接、逐通道 Conv1d 聚合、MLP、标量二分类输出；训练采用数值稳定的 BCE logits 形式，推理输出 sigmoid 概率。 |
| 五折训练 | 固定读取完整五折，不再只运行历史脚本中的部分折；检查患者泄漏、路径别名和跨折标签一致性。 |
| 类别平衡 | 仅在训练采样时平衡类别，验证集保留原分布。 |
| 模型选择 | 最多 200 epochs；验证损失连续 20 epochs 不改善则早停，保存最低验证损失的检查点。 |
| 指标 | AUC 使用连续概率；其他指标按固定阈值计算，明确 1 代表 GG3–5 或 EPE-positive。 |
| 数据与运行 | 路径、标签编码、权重和训练配置均通过参数提供；不再需要缓存的二维特征。 |
| 工程 | 增加 README、ISUP/EPE 配置、预处理、推理、合成示例和自动检查；历史恢复包保留为单独备份。 |

## 验证情况

CPU 上已验证核心前向与反向计算、冻结策略、双向超图更新、权重迁移的完整性检查及预处理。两项任务均已在合成数据上跑通完整五折训练，并验证最低验证损失检查点的保存和重载推理。

完整默认模型也已通过输入尺寸为 `(1,1,96,224,224)` 的前向检查。

| 参数范围 | 总参数 | 可训练参数 |
| --- | ---: | ---: |
| 编码器 | 104,878,080 | 19,860,480 |
| 整网（含超图与分类头） | 129,799,937 | 44,782,337 |

文稿中的 104.88M / 19.86M 对应编码器，不能将其直接表述为整网参数量。

## 需要明确的边界

- 这是按文稿对齐后的实现，不能把历史结果直接标为新代码已经复现的结果。仍需在真实数据、原有五折和实际 BiomedCLIP 权重上重新训练验证。
- 目前使用合成的兼容权重字典测试预训练迁移规则，尚未加载完整的真实 BiomedCLIP 权重文件。
- 默认保留恢复工程中的 96³ 裁剪后平面内缩放至 224×224 的设置，该设置与文稿编码器参数量吻合。建议在方法中明确写出这一缩放步骤。
- 默认学习率 1e-5、超边数 8、相似度头数 4、MLP 隐层 128 等均在配置和 README 中写明；不能据此认定它们就是所有历史实验的精确设置。
- 临床数据、患者级划分、模型权重及训练输出均未加入公开代码包。
